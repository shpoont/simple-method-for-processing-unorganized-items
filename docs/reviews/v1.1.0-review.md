## Coverage of the agreed direction

An independent subagent compared the draft with the agreed requirements and
the original method. It found all points covered and no weakened baseline rule.

| Point | Guidance in the method |
| --- | --- |
| Collection, scope and action targets | Opening definitions and the booking-email example distinguish the three boundaries. |
| Discovery and membership | Optional expansion; examples beyond browsing and search; purpose, evidence and exceptions confirm membership. |
| Refinement toward one action | Prefer one appropriate shared handling action, provisionally; preserve dependencies and justified combinations. |
| Flexible final decisions | Several actions can target one scope; the final actions, targets, effects and conditions determine approval. |
| Investigation | Evidence can improve membership or handling; outside sources remain context with separate authority. |
| Worthwhile effort | Consider expected improvement, cost, consequences, existing evidence and later use rather than item count alone. |
| Large and nested collections | A boundary does not require an inventory; container handling and individual examination are distinct. |
| Ordering | Default to discovered eligible items; require evidence for an explicitly required whole-collection order. |
| Preserved safeguards | Authority, conditions, verified completion, shared obligations, uncertainty recovery, reliable follow-up intake and bounded coverage remain. |

One wording improvement from this comparison was applied: a costly comparison
may be worthwhile before deleting a file **that may be unique**. This makes the
uncertainty the comparison can resolve explicit.

## Paper walkthroughs

The practicality reviewer derived these paths from the method. The outcomes
describe what the guidance supports, rather than actions performed on real data.

| Situation | Supported path and evidence still needed |
| --- | --- |
| Archive proposal becomes delete 15/archive 5 | Keep one scope; identify both target sets and their order; obtain authority for the actual actions and check both outcomes. Earlier archive-only approval does not cover deletion. |
| Similar filenames, different contents, one uncertain identity | Treat results as candidates; confirm purpose, identity, relationship and exceptions. Leave unresolved membership pending. |
| Globally newest item in a partly discovered hierarchy | Establish the required order through a view or evidence covering the eligible population and ties. Without sufficient evidence, selection remains blocked. |
| Related work items have shared dependencies and different handling | Keep joint consideration where dependencies warrant it; use the correct action targets and confirm shared results before completion. |
| A download is compared with a protected reference library | Use authorized inspection as context for the download decision. Require an adequate comparison; relevance does not authorize changes to the library. |
| Million-item investigation, differing error consequences and prior evidence | Weigh improvement, cost, consequences and reuse. Check that prior evidence still applies; item count alone does not prescribe effort. |
| A folder move affects included and excluded descendants | Make effects explicit and ensure authority and conditions cover them. Verify handling of included contents without claiming individual inspection. |
| A batch has uncertain partial results and unfinished work needs handoff | Establish effects before retry, reuse confirmed successes and keep unresolved work tracked. Confirm receiving-workflow acceptance; a note alone is insufficient. |
