# A Simple Method for Processing Unorganized Items

A simple, human-readable method for working through a collection one item or
group at a time. Choose the scope, decide what to do, then act and check the
results. The same guidance applies to people and agents.

Author: **Leon.id Komarovsky** — [leonid@komarovsky.info](mailto:leonid@komarovsky.info)

## Documents

- [Method v1.0.0](docs/simple-method-for-processing-unorganized-items.md) — the

- [Decision log](docs/decision-log.md) — lasting decisions and their rationale.

- [Changelog](CHANGELOG.md) — summaries of changes by version and repository
